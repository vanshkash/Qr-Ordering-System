# QR Restaurant Ordering System

A modern QR-based restaurant ordering system that allows customers to scan a table QR code, browse the menu, place orders, and enables kitchen staff to manage orders in real time.

##  Features

- QR Code Based Table Identification
- Digital Restaurant Menu
- Category-wise Food Listing
- Add to Cart Functionality
- Place Orders Directly from Mobile
- Real-Time Kitchen Dashboard
- Live Order Status Updates
- Order Tracking (Pending → Preparing → Served)
- Mobile Responsive Design
- Real-Time Communication using Socket.io
